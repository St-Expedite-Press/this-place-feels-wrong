# St. Expedite site

Astro static site for St. Expedite Press.

- source: `apps/stex/src/`
- authored assets: `apps/stex/public/assets/`
- generated output: `apps/stex/dist/`
- build command: `npm --prefix apps/stex run build`
- preview command: `npm --prefix apps/stex run preview`

The homepage and all interior pages are generated from source. Do not edit generated output by hand.
